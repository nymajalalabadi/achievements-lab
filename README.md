# achievements-lab

A small sandbox repository used to practice and document GitHub workflows: issues, branches, pull requests, code review and discussions.

## Why this repo exists

Every day work on GitHub is built from a few simple habits: describe the work in an issue, do the work on a short lived branch, open a pull request so the change can be read as a story, then merge and close the issue. This repository is a safe place to rehearse those habits without touching a real project.

## Workflow used here

Work starts as an issue that explains the problem in one or two sentences. A branch is created from main with a short descriptive name. The change is committed with a message that says why, not just what. A pull request links back to the issue and is merged once it is green.
